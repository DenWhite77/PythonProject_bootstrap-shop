# Bootstrap Shop

Проект интернет-магазина, созданный в рамках обучения веб-разработке и работе с Python.

## Технологии

- HTML5
- CSS3
- Bootstrap 5.3.3
- Python 3
- `http.server`
- `urllib.parse`
- Git

## Возможности

- Главная страница интернет-магазина
- Каталог товаров
- Страница категорий
- Страница заказов
- Страница контактов
- Навигация между страницами
- Адаптивная вёрстка с использованием Bootstrap
- Обработка GET-запросов сервером Python
- Обработка POST-запроса формы обратной связи
- Вывод полученных данных формы в консоль
- Обработка ошибок 404 и 500

## Запуск проекта

Для запуска сервера необходимо перейти в директорию проекта и выполнить:

```bash
python server.py
```

После запуска сервер будет доступен по адресу:

```text
http://localhost:8080
```

## Обработка формы

На странице «Контакты» реализована форма обратной связи.

Форма отправляет данные методом `POST`. Сервер получает данные, обрабатывает их с помощью `urllib.parse.parse_qs` и выводит имя, email и сообщение в консоль.

После успешной отправки пользователь получает сообщение:

```text
Данные получены!
```

## Обработка ошибок

Сервер обрабатывает следующие ситуации:

- `404` — страница не найдена
- `500` — внутренняя ошибка сервера
